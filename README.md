# Fluxogramas do site da escola

Fluxogramas do **Agenda Escolar** do Colégio Estadual Presidente Kennedy,
desenhados com os símbolos corretos:

- **elipse** — início e fim;
- **retângulo** — processo;
- **losango** — decisão;
- **paralelogramo** — entrada/saída;
- **setas** — caminho do fluxo.
